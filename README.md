# Aon 写真展「Tayutau」道案内

2027年3月5日（金）〜11日（木）、PENNY LANE GALLERY（コピス吉祥寺 A館 1階）で開催する
Aon 写真展「Tayutau」の、吉祥寺駅北口からギャラリーまでの道案内ページです。

```
access/index.html  道案内ページ（地図・手順・現在地表示・Googleマップへのリンク）。単体で動きます
index.html         トップにアクセスしたときに access/ へ移動させるページ
```

- 会期・時間・住所・手順の文章は `access/index.html` に直接書いてあります。そのまま書き換えてください
- 地図データ © OpenStreetMap contributors（表示は消さずに残してください）
